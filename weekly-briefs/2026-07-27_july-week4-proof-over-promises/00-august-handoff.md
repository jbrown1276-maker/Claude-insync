## Pipeline Procedure Fix — Devon Asset Production

The most significant process lesson from the July arc:

**Devon's Stage 3 approval (design system spec) ≠ SVG files actually saved to disk.**

For July Weeks 2, 3, and 4, the design system documents were approved through the gate without any files being built. The gap was only caught when Jeff asked directly. All 35 SVG source files were built retroactively.

**Corrected procedure for August and all future weeks:**

1. Stage 3 approval gate covers the **design system spec document** (`03-devon-design-system.md`). Approve as normal.
2. After spec approval, run a **second Devon invocation** with an explicit prompt: "Build and save the SVG files specified in the approved design system. Use the Write tool to save each file to `assets/` within the campaign folder. Write each file completely — do not summarize or describe. Confirm with file size after saving."
3. After the Devon build run, **verify with `ls -lh`** on the assets folder. Zero-byte or missing files = the run stalled. Re-run.
4. PNG export sprint follows SVG production. Do not advance to Stage 4 without SVG source files confirmed on disk.
